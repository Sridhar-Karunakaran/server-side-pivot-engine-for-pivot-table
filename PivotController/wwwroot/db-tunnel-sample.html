Pivot Table — PostgreSQL Data Server Index (Server Mode)

This grid runs in Server mode: the Data Server fetches rows from the Sales-Db PostgreSQL index (connection string + SQL query configured on the server), and all pivot calculations, aggregation, filtering, sorting and report generation execute server-side via /api/pivot/post — only the computed viewport is sent to the browser. The client-side report settings below match the index data source fields (country, product, year, quantity).
